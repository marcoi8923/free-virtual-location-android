# 模拟定位 MockLocation v1.5 使用说明

自研安卓模拟定位 App：**摇杆控制位置 + 配速可调**，支持**手机 GPS 真实定位**、**悬浮窗摇杆**、**多地图源切换**。
源码可改、无加固、不联网上传任何数据。

## 一、v1.5 新增：地图源可选 + "map data not yet available" 修复

**1）为什么会一直显示 "Map data not yet available"？**

那是 **Esri 图源**在它没有数据的区域/层级返回的**灰色占位图片**（不是你的网络问题）。
上一版为了提速做了"自动选最快图源"，而 Esri 响应快（0.38s）就被选中了，结果它在你所在区域没有数据 → 满屏灰底占位图。

**2）现在的解决办法**

| 改动 | 说明 |
| --- | --- |
| **占位图自动识别** | 识别出这种"灰底占位瓦片"（采样超过一半像素是 (204,204,204)）直接当作下载失败，不再显示出来 |
| **手动选图源** | 地图右上角新增「**源**」按钮，可选：自动 / OSM 官方 / OSM 德国镜像 / Esri 世界街道图 / **高德地图（中文）**，选择会记住 |
| **高德自动坐标纠偏** | 高德用 GCJ-02 火星坐标，与 WGS-84 差 300~600 米（实测北京 554.9 米）。选高德时 App 会**自动做双向纠偏**，地图和你设定的位置依然对得上 |
| **明确的提示** | 当前图源在该区域没数据时，地图上会提示"当前图源在此区域没有数据，点右上「源」更换地图源" |
| **修掉一个后台崩溃** | 快速切换图源时，下载线程里可能拿到旧下标导致 `ArrayIndexOutOfBoundsException` 崩溃，已修（改为取快照 + 下标校验） |

实测：高德中文地图正常渲染（6615 种颜色，占位灰仅 0.3%）；连续快速切换 8 次图源无崩溃；地图覆盖率 92.3%。

## 二、v1.4 地图速度优化（仍然有效）

| 优化 | 效果 |
| --- | --- |
| 先粗后细预加载（预取 z-2/z-3 祖先瓦片） | 冷启动 3 秒地图覆盖 93.5%（优化前同时间 2.5%） |
| 没下载好的位置用上层瓦片放大顶替 | 拖动/缩放时不再大片空白 |
| 图源并行探测选最快 + 失败冷却重试 | 不用逐个白等超时 |
| 下载线程 6 个 + 轨迹路径缓存 + 减少每帧分配 | 拖动更跟手 |
| 地图右上按钮改为横排一行、地图高度 +26% | 修复之前四按钮被裁掉的"错位"问题 |

## 三、手机 GPS 真实定位（v1.3）

| 功能 | 用法 |
| --- | --- |
| **获取定位** | 点「获取定位」持续读 GPS/网络定位；信息栏显示经纬度、精度 ±米、来源、距今秒数 |
| **设为起点** | 把模拟位置立刻设成真实位置，地图同时居中 |
| **跟随定位** | 模拟位置持续跟随手机真实定位（模拟服务后台运行也生效） |
| **地图蓝点** | 蓝点＋蓝色精度圈＝手机真实位置；绿色图标＝当前模拟位置 |

## 四、安装

1. 把 `MockLocation-1.5.apk`（294 KB）传到手机（微信/QQ 文件传输助手或数据线）。
2. 手机上点它 → 允许"未知来源" → 安装（可直接覆盖 1.4，签名相同）。
3. 支持 Android 5.0 ~ 16。

## 五、首次使用

1. 第一次打开会自动弹出**使用说明长图**（8 个步骤），可上下滑动，点底部「我已了解，开始使用」进入主界面（只弹一次，之后点「使用说明」可再看）。
2. 必须做一次：「设置 → 关于手机 → 连点版本号 7 次」开启开发者模式 → 「设置 → 系统 → 开发者选项 → 选择模拟位置信息应用」→ 选中「**模拟定位**」。
3. 回到 App 点绿色「**开始模拟**」；状态显示「等待授权」就是第 2 步没选上。

> 建议：打开系统定位开关（读真实定位需要）；点右上「省电优化」允许后台常驻。

## 七、图源怎么选（建议）

| 你的情况 | 建议图源 |
| --- | --- |
| 在国内、想看中文地图 | **高德地图（中文）**（最快，且会自动纠偏） |
| 想看国际风格、英文地名 | **OSM 德国镜像**（国内一般可访问；OSM 官方在国内常连不上） |
| 不确定 | **自动**（启动时测速选最快的可用图源） |
| 想用 Esri | 可以选，但**国内很多区域没有数据**，会提示"当前图源在此区域没有数据" |

## 九、已知限制

- 高德/OSM/Esri 都是公开瓦片接口，个别地区或个别时段可能限速；加载不出来会自动切网格底图，可点 ↻ 重试或换图源。
- 无 ROOT 方案固有限制：部分 App（银行、部分游戏反作弊）会检测并忽略模拟位置。
- 悬浮窗需「显示在其他应用上层」权限；部分国产系统还要求「后台弹出界面」权限。
- 室内 GPS 精度会下降（显示更大的 ±米数），这是系统定位本身的特性。
